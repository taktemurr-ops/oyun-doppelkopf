# Doppelkopf · Doppelkopf

Takımın gizli: sinek kızları kimde, elleri al!

Almanya'nın dört kişilik çift desteli koz oyunu: sinek kızlarını tutanlar gizli Re takımıdır. Para yok, yalnızca puan listesi. 100.000 üretilmiş ve doğrulanmış bölüm, 33 dil. Kart Oyunları merkez uygulamasının oyunu; ortak motor: kart-motoru.
